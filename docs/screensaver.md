# Local screensaver

General → Local screensaver timeout offers Off (default), 1, 5, 10, 15, 30, 45
or 60 minutes on a discrete slider. Local screensaver style selects a moving dim clock or imported images
with a dim clock. Images change every thirty seconds from the offline personal
catalog. The clock moves every fifteen seconds; presentation refreshes at most
once per second. This does not change Home wallpaper selection or fetch images.

Idle time counts only while Lumaglass is visible/focused and no dialog, text
keyboard, reorder, held activation or app launch is active. Leaving the app
starts a fresh idle interval. The first input dismisses the saver and is consumed;
a waking key/button stays suppressed through its release. Arrows, OK and Back
therefore do not activate the hidden launcher on the same waking gesture.

LG's own screensaver, standby and panel-protection policies remain enabled.
This mode applies only inside Lumaglass; it does not replace the system saver
while another app or HDMI input is active. A system-wide adapter is a separate
future integration requiring firmware-specific verification. No claims of
burn-in prevention are made. Actual TV power/standby behavior awaits verification.

Use the header control center to start the screensaver immediately, even when the automatic timeout is Off. The native LG sleep timer is a separate control; see [control center](control-center.md).
